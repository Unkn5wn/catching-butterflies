# 🦋 Catching Butterflies

A fun 3D browser-based game where you catch butterflies, spiders, and underground creatures across three unique levels!

## 🎮 Game Preview

### Level 1: Kids Park (Day) ☀️
Catch 101 colorful butterflies in a bright, sunny park surrounded by trees!
- **Environment**: Bright blue sky with green grass
- **Creatures**: 3 types of butterflies (Monarch, Blue Morpho, Swallowtail)
- **Objective**: Catch 101 butterflies to advance

### Level 2: Night Forest 🌙
Hunt spiders in a dark, mysterious forest illuminated by colorful flowers!
- **Environment**: Dark night sky with dim lighting
- **Creatures**: Spiders crawling on the ground
- **Objective**: Catch 50 spiders to advance

### Level 3: Underground 🪱
Explore the underground world and catch various creatures!
- **Environment**: Brown earthy terrain
- **Creatures**: Ants 🐜, Worms 🪱, Snails 🐌, Bugs 🐛, Crickets 🦗
- **Objective**: Catch 20 of each creature type to complete the game

## ✨ Features

- 🎯 **3 Unique Levels** with different environments and creatures
- 🛒 **Shop System** - Buy nets and character upgrades
- 🎮 **Multiple Control Options** - Keyboard (WASD) and Gamepad support
- 👤 **6 Playable Characters** - Default, Astronaut, Police, Elf, Pilot, Firefighter
- 🥅 **3 Net Types** - Basic, Advanced, and Rare nets with different ranges
- 💰 **Economy System** - Earn money by catching creatures
- 📊 **Progress Tracking** - Real-time counter for each level's objectives
- 🎨 **3D Graphics** - Built with Three.js for smooth 3D rendering

## 🎮 How to Play

### Controls

**Keyboard:**
- `W/A/S/D` - Move player
- `Arrow Keys (Left/Right)` - Rotate camera
- `SPACE` - Catch creatures
- `E` - Open/Close Store
- `ENTER` - Select menu options

**Gamepad (Nintendo Switch Pro Controller):**
- `Left Stick` - Move player
- `Right Stick` - Rotate camera
- `A Button` - Catch creatures / Select
- `+` (Plus) - Open Store
- `D-Pad Up/Down` - Navigate store menu

- **Engine**: Three.js (3D rendering)
